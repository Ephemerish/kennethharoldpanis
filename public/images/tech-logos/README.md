# Tech Logos

Add your technology logos here. Supported formats: PNG, SVG, JPG

## Recommended Sources for Tech Logos

1. **Simple Icons** - https://simpleicons.org/
   - Free SVG icons for popular brands
   - Download individual icons

2. **SVGRepo** - https://www.svgrepo.com/
   - Search for tech logos
   - Free SVG downloads

3. **Official Brand Resources**
   - React: https://react.dev/
   - TypeScript: https://www.typescriptlang.org/branding/
   - Node.js: https://nodejs.org/en/about/branding/
   - Most companies have a "brand assets" or "press kit" page

## Image Guidelines

- **Format**: PNG with transparent background or SVG preferred
- **Size**: 200x200px or larger (will be resized automatically)
- **Naming**: Use lowercase with hyphens (e.g., `react.svg`, `node-js.png`, `typescript.svg`)
